# Repository-Arbeitsregeln

- Für Zugriffe auf Jira-Tickets die Repository-Skills unter `.github/skills/jira-tickets` verwenden.
- Für Zugriffe auf Confluence-Seiten die Repository-Skills unter `.github/skills/confluence-pages` verwenden.
- Für diese Jira- und Confluence-Vorgänge keinen Browserzugriff verwenden.
- Für Jira-Automatisierungsregeln den [zentralen Skill](../ai-collaboration-skills/skills/jira/jira-automation-rules/SKILL.md) lesen; Regelstarts und Ergebnisprüfungen ausschließlich per API durchführen, ohne Browser oder Computer Use.
